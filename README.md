# 미션픽 🐤

지역을 탐색하며 미션에 참여하는 멋쟁이사자처럼 13기 중앙 해커톤 프로젝트입니다.

## 주요 기능

- **계정 관리:** 회원가입 및 로그인
- **미션:** 미션 목록과 상세 정보 확인
- **참여 기록:** 미션 참여 화면과 마이페이지
- **랭킹:** 리더보드 확인
- **상점:** 서비스 내 상점 화면

## 기술 스택

- **Frontend:** React, JavaScript, Create React App
- **Styling:** styled-components
- **Routing:** React Router
- **API:** Axios
- **UI:** Framer Motion, Recharts

## 실행 방법

```bash
npm install
npm start
```

프로덕션 빌드:

```bash
npm run build
```

서버와 연동되는 기능은 별도의 백엔드 환경이 필요합니다.
